# CodeJam 2026

Each project lives on its own branch:

| Branch | Project |
|---|---|
| `rarefind` | Rarefind: a photo game played outside. A prompt names a kind of thing, you photograph one, and your card's tier depends on how few other players found the same thing. |
| `squall` | Squall: a GPS bullet hell. Walk out of danger zones in real life, and revive teammates by walking to them. |
| `brim` | Brim AP: accounts-payable automation for the Brim fintech challenge. |
